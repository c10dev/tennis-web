# 텍스트 커리어 "주니어에서 그랜드슬램까지" (M9, ADR-032)

2026-10-18 피벗. kickru.com("벤치에서 발롱까지")의 루프를 테니스로 옮긴다. 3D 퀵매치·중계 코드는 그대로 두고 메인에서 내린다(`?legacy=1`).

## 1. 루프
- **짧은 루프 (구간 하나, 10–30초):** 구간 계획(일정 강도·집중 훈련) → "구간 보내기" → 리포트(대회 성적, 랭킹 변화, 능력치 변화, 뉴스, 댓글) → 0–2개 라이프 이벤트·제안.
- **긴 루프 (커리어 하나, 15–30분):** 14세 주니어 → 프로 전향 → 투어 → 은퇴(대략 30–38세) → 커리어 요약·닮은 레전드·명예의 전당 → 새 커리어.
- 한 해 = 4구간, 구간마다 메이저 하나로 끝난다: 1 호주(하드, 멜버른 메이저) · 2 클레이(파리 메이저) · 3 잔디(런던 메이저) · 4 북미 하드(뉴욕 메이저) + 연말 파이널스.

## 2. 선수
- **생성:** 이름, 국적, 주 손(표시용), 플레이 스타일 → 후보 3명(모두 OVR 45, 6개 그룹 분포만 다름) 중 선택 → 집중 육성 그룹 1–2개.
- **표시 능력치:** 엔진 1–20 레이팅을 6그룹 0–100으로 묶는다 (`display = rating × 5`의 그룹 평균).
  - 서브(servePower, serveAccuracy, secondServe) · 스트로크(forehand, backhand, consistency) · 리턴(return) · 네트(volley, overhead, slice, dropShot) · 피지컬(movement, agility, stamina, strength) · 멘탈(composure, concentration, decision, aggression).
  - OVR = `overall()`(가중 평균 1–20) × 5, 반올림.
- **숨은 값:** 잠재력(1–20 스케일 OVR 상한), 사기(0–100), 명성(0–100), 돈, 피로, 부상 주 수.
- **성장:** M4 `endWeek` 재사용(나이 계수 × 잠재력 여유). 주니어(≤17)는 훈련만으로도 크게 큰다.

## 3. 월드
- 이름 있는 프로 풀(약 160명, 18–36세) + 해마다 생기는 주니어 코호트(나이별 약 24명, 14–17세). 18세가 되면 상위 주니어는 프로 풀로 올라온다 → 주니어 라이벌이 투어 라이벌이 된다.
- 연말: 나이 +1, AI 성장/노화, AI 은퇴(나이·순위), 새 코호트 유입.
- 풀 밖 순위(161위 이하)는 포인트→순위 곡선으로 추정해서 보여준다.

## 4. 대회와 랭킹
- 등급: 주니어(J300 / 주니어 메이저), 퓨처스, 챌린저, 250, 마스터스, 메이저, 파이널스. 포인트는 M4 `TIERS` 패턴(라운드별)을 확장.
- 출전: 52주 랭킹 순으로 컷. 일정 강도가 구간당 출전 수를 정한다(빡빡 4–5개, 보통 3개, 메이저 집중 1–2개 + 메이저).
- 랭킹: 최근 4구간 포인트 합(롤링 52주). 주니어 랭킹은 따로.
- 내 경기는 엔진 전체 시뮬, AI끼리는 빠른 모델(§7).

## 5. 선택
- **일정 강도:** 빡빡(포인트↑, 피로·부상↑) / 보통 / 메이저 집중(훈련↑, 랭킹 포인트↓).
- **집중 훈련:** 1–2그룹, 바꾸기 전까지 유지.
- **라이프 이벤트:** `{id, title, text, when(state), options:[{label, detail, effect | gamble}]}`. 효과는 사기·명성·돈·능력치·피로. 구간마다 0–2개.
- **제안:** 코치(돈 → 성장 배율), 스폰서(돈·명성, 대신 조건), 아카데미(주니어), 대학(주니어 말, 프로 전향 대안).

## 6. 텍스트
- 한국어만(영어는 TD). kickru 톤: 기사 헤드라인("{name}, 런던 메이저 첫 4강… 한국 테니스의 새 이정표") + 커뮤니티 댓글(밈 톤, 짧게).
- 템플릿은 조건(성적·나이·연속 기록)과 가중치를 가지고 시드로 고른다. 조사는 `withJosa`.
- 큰 경기(메이저 4강·결승, 주니어 메이저 결승)는 엔진 이벤트로 텍스트 중계: 세트·게임 흐름 한 줄씩, 브레이크·세트·매치 포인트는 `captionBefore`/`ending` 문장.

## 7. 빠른 경기 모델
- AI끼리 경기: 포인트 단위 베르누이. 서버의 서브 포인트 승률 `p = base(surface) + k × (서버 레벨 − 리시버 레벨)`을 게임·세트·타이브레이크 규칙으로 굴린다.
- 엔진 배치에 맞춰 보정한다: 레벨 차 0–4에서 매치 승률이 엔진과 ±4%p 이내 (`fast-match.test.ts`).
